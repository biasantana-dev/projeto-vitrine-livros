# Vitrine de Livros 📚

Este é um projeto simples que criei para treinar meu desenvolvimento web (HTML, CSS e JavaScript). 

A ideia principal foi fazer uma página de livros onde a capa some e mostra a sinopse quando a gente interage com o card.

## ⚙️ Como funciona?
* **No computador:** Quando você passa o mouse em cima do livro, a capa desaparece e o texto da sinopse aparece. O card também sobe um pouquinho.
* **No celular:** Como não tem mouse, basta dar um toque no card para ver a sinopse, e outro toque para voltar a ver a capa.

## 🛠️ O que eu usei para fazer:
* **HTML5:** Para colocar os textos, títulos e as imagens na página.
* **CSS3:** Para criar o visual escuro (Dark Mode), organizar os livrinhos em colunas (usando CSS Grid) e deixar as capas na proporção certa de um livro.
* **JavaScript:** Um código bem curtinho para fazer o clique no celular funcionar.
